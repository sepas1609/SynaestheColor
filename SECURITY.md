# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The SynaestheColor maintainers take security seriously. If you discover a security vulnerability in this project, please follow these steps:

1. **Do not create a public GitHub issue.**
2. Send a confidential report outlining the issue, steps to reproduce, and potential impact to the repository maintainers via GitHub Security Advisories or direct private contact.
3. We will acknowledge receipt of your vulnerability report within 48 hours and provide a timeline for remediation.

### Safe Harbor
We support responsible disclosure and will not take legal action against researchers who report vulnerabilities responsibly according to these guidelines.
